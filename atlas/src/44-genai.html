On main

MethodPathWhat it does
GET/health-checkReturns {"status":"ok"}. No auth.
POST/test/chat-agentSends the user's text to gpt-4o-mini with a one-line system prompt.
POST/test/sql-agentNatural language to SQL. gpt-4.1-mini writes SQL against a prompt containing the patients and cases DDL. The service runs the SQL on the MySQL reader and sends the rows back to the model.
GET/test/db, /test/validationA fixed vancomycin case count, and an echo.
  • Auth. Cookie tokens are checked against five Cognito pools, followed by the revocation check (RX-3302), which fails open at runtime. main doesn't check the audience, token_use, the id token's expiry, token pairing or roles.
  • Data scope. The database schema is hard-coded to one institution, whatever the caller's license is (services/db.py:13). Query rows, which can include names, birthdays and MRNs, go to OpenAI. No code shows whether a BAA or zero-retention agreement covers this.
  • SQL safety. Read-only behaviour depends only on connecting to the reader endpoint. There is no statement allowlist, LIMIT or timeout, and the MySQL connection sets no TLS options.
Shared list across requests

correct_sql_query declares failed_queries: List[FailedQueryRun] = [] as a default argument (agents/sql.py:200). Python creates that list once per process, so failed SQL and its error text from earlier requests, possibly other users', accumulate and are returned in later responses. The retry at line 244 is also missing await and passes its arguments in shifted positions, so a second failure becomes a TypeError. The risk is low if main is never deployed; only feature/rx-2901 has a Jenkinsfile.

On feature/rx-2901 (skimmed, not audited)

  • Size and entry point. 220 files. The entry point is preciserx_genai.app:app on ${SERVER_PORT:-8080}, in a multi-stage python:3.13-slim image.
  • Routes.
    • /HealthCheck, rate-limited.
    • /assistant/token-usage and /assistant/cache.
    • POST /ag-ui, the CopilotKit streaming assistant. It requires auth, an assistant-permission check and a monthly token limit, and allows 40 requests per minute per user.
    • POST /solana-ag-ui.
  • Models. gpt-5.1 through the Responses API for the PK and support agents, and text-embedding-3-small for embeddings.
  • Dependencies. PK-Library's Python bindings from its feature/rx-2901 branch; PostgreSQL through asyncpg and psycopg; logfire, which is unscrubbed in development; slowapi; structlog.
  • Missing revocation check. It has no token-revocation code. RX-3302 landed only on main.
  • Usage records. Database already has /license/tokens/* and /license/llm-usage endpoints documented as receiving usage from GenAI.
