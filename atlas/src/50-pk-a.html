PK-Library, the dosing engine

For a patient and a drug, the engine does four things. It estimates population PK parameters from a published study. It fits those parameters to measured levels by Bayesian MAP estimation (the most probable parameters given both the prior and the data). It simulates concentration over time. And it searches for a regimen that hits a target. Main, Analytics and Databridge load it in-process as a native Node addon.

PK-Librarystudy/vancomycin/vancomycinrodvold1988.hpp

Worked example: vancomycin, Rodvold 1988

Rodvold 1988 is the default vancomycin model for general adults. It is a two-compartment model with two fitted parameters, clearance (CL) and the terminal-phase volume (Vdβ). The file is header-only.

Where each piece comes from

ClassWhat it contributes
VancomycinRodvold1988The population formulas for CL, Vdβ and Vc; model name, study summary, age and weight ranges, sources; can_fit() = true, which allows local population refitting.
VancomycinTDMSFits VD_BETA and CL. Fixes k21 = 0.46 h⁻¹. Derives β, k12 and the other constants. Builds a time-varying CL multiplier when the patient has more than one CrCl entry. Declares parameter limits that are never applied (see below).
VancomycinTwoCompartmentF = 1 (RSD 0.05), salt factor 1, and an absorption rate for IM only: 2.7 if age > 75, otherwise 1.9.
TwoCompartment → LinearModel → ModelThe two-compartment closed-form concentration, the dose-from-target maths, and the shared simulation and search machinery.

Clearance prior

CLpop = a · CrCl(t) + b · Wadj

where

CLpop
population estimate of the patient's vancomycin clearance, L/h
CrCl(t)
creatinine clearance in effect at time t, mL/min (patient.crcl_at(datetime))
t
the time the estimate is for; CL can differ between dosing intervals when CrCl changes
Wadj
adjusted body weight, kg
a
0.79 × 0.06 = 0.0474 (L/h) per (mL/min). 0.79 is the Rodvold 1988 slope of vancomycin CL on CrCl; 0.06 converts mL/min to L/h.
b
0.05 × 0.06 = 0.003 (L/h) per kg. 0.05 mL/min/kg is non-renal clearance from Rodvold 1989.

Prior CV 0.5, with the comment // source?. vancomycinrodvold1988.hpp:20-28, 33-66

Volume prior

Vdβ,pop = d · Wdose · m

where

Vdβ,pop
population estimate of the volume of distribution in the terminal (β) phase, L
Wdose
dosing weight, kg (the engine chooses actual, ideal or adjusted weight by its own rules)
d
0.7 L/kg. For adults with CrCl below 10 mL/min it is 1.0 L/kg (Tan 1990), and the ICU factor is not applied.
m
1.13 if the patient is critically ill or in ICU, otherwise 1

Prior CV 0.3. vancomycinrodvold1988.hpp:71-98; Tan 1990 branch in vancomycintdms.hpp:149-163

Values that are not fitted

Vc = 0.17 · Wdose (0.45 · Wdose for adults with CrCl < 10)

β = CL / Vdβ k10 = CL / Vc k21 = 0.46 α = k10 · k21 / β k12 = α + β − k21 − k10

where

Vc
volume of the central compartment, L
CL, Vdβ
the clearance and volume in use: the prior values, or the fitted ones after a fit
β
slow (terminal) rate constant of the concentration curve, h⁻¹
α
fast (distribution) rate constant, h⁻¹
k10
elimination rate constant from the central compartment, h⁻¹
k12, k21
transfer rate constants from central to peripheral and back, h⁻¹. k21 is a constant "calculated using three data sets".

Vc: vancomycinrodvold1988.hpp:100-149. β, k21, k12: vancomycintdms.hpp:115-147, 194-199. k10 and α come from shared helpers

For the sample patient in the header (70 kg, CrCl 100 mL/min), these give CL = 4.95 L/h, Vdβ = 49 L, Vc = 11.9 L, β = 0.101 h⁻¹, k10 = 0.416 h⁻¹, α = 1.89 h⁻¹ and k12 = 1.12 h⁻¹.

Limits that are declared but never applied

VancomycinTDMS::fitted_param_constraints would keep β below k21. It sets a floor on Vdβ of 1.01 · CL / k21 and a ceiling on CL of 0.99 · k21 · Vdβ (vancomycintdms.hpp:165-174). Nothing calls fitted_param_constraints, for any model. The base class returns empty maps (model.cpp:49).

If a fit drove β above k21 while β stayed below k10, the formula above would make k12 negative. In practice β is far below 0.46 h⁻¹ for most patients, but nothing enforces it.

Details a reader would miss

  • CL reads CrCl at each point in time. Vdβ and Vc read only the latest CrCl (patient.crcl()), including for the CrCl < 10 switch. So a patient whose kidneys recover gets a time-varying CL but the latest-CrCl volumes throughout.
  • Lines 35-38 read age, weight and scr, and none of them is used.
  • Line 54 asks "Are these sources even used??" about nine of the citations attached to CL. Those citations are shown to clinicians.
  • A patient with two or more CrCl entries has a time-varying CL. That turns off the closed-form shortcut, so every prediction for that patient is simulated numerically (see Simulation).
