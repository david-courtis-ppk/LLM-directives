Known issues

Confirmed problems, ordered by risk within each group. Several need a clinical or compliance decision, not just a code change, so raise them with the owning team rather than fixing them alone.

Could affect a dose or lose clinical work

High A failed save stops all saving, silently

The save status stays at "saving" after any failed save, because the code that should flag the failure watches the wrong route. From then on, neither manual save nor autosave runs. PreciseRx-Web/src/components/User/Save/SaveContainer.tsx:177-181; src/actions/ApplicationActions.ts:254-285. Details

High Engine failures come back as success

PK-Library catches its own exceptions and returns {} (or -1), and Main returns that with HTTP 200. On fit-and-plot, the frontend then keeps the previous curves and fitted values on screen. PK-Library/bindings/nodejs/pklibraryjs.cpp:1947-1951; PreciseRx-Main/src/controllers/prediction/dose/post-output.js:28-43; PreciseRx-Web/src/actions/GraphingActions.ts:216-220. Details

High Main never rejects malformed clinical input

46 controllers ignore Joi's error and pass the body to the engine as it came in. PreciseRx-Main/src/utils/validation.js:36-84. Details

High An unexpected weight or height unit is treated as kg or cm

Any unit other than exactly kg, lb, cm or in makes the engine rebuild the patient in kg and cm, keeping the same numbers. Main accepts any string. The frontend sends only valid strings today, but nothing else guards this. PK-Library/bindings/nodejs/unraveler.cpp:46-50; PreciseRx-Main/src/schemas.js:40.

Medium The optimizer's safety rails don't engage

Declared parameter limits are never applied. A fit that hits the 1,000-iteration cap reports SUCCESS. The prior covariance is never captured, because iter is incremented before the iter == 0 check. PK-Library/src/pharmacokinetics/study/vancomycin/vancomycintdms.hpp:165-174; bayesianfitting/bayesianfitting.cpp:238, 269, 284, 332. Details

Medium Loading-dose rounding can pick the worse option

When rounding is on, the engine compares rounding the loading dose up, rounding it down, and dropping it. The loop never updates its running minimum, so it keeps the last option that beats round-up, not the best of the three. PK-Library/src/pharmacokinetics/doseprediction/dosageregimen.cpp:243-247.

Medium Invalid institution settings silently fall back to defaults

That includes the CrCl formula the institution chose. PK-Library/bindings/nodejs/unraveler.cpp:27-31.

Medium Model Analytics shows NRMSD under the wrong formula

The value is √MSE ÷ mean(observed). The formula shown next to it is √(Σ(O − P)² / Σ(O − Ō)²). PreciseRx-Web/…/SerumPredictionAnalytics/utils/calculateStatistics.ts:109-119; SerumPredictionStatistics.tsx:54.

Low One engine function aborts the whole Node process on bad input

route_information is the only exported function without a try. An unknown drug or route name throws a C++ exception, which node-addon-api does not convert, so the calling service exits. Its only caller, Databridge, validates both names first, so it can't be triggered today. PK-Library/bindings/nodejs/pklibraryjs.cpp:3148-3156; PreciseRx-Databridge/src/model/redux/redux-dosage-history.js:34-46, 531-533.

PreciseRx-Web/src/components/User/Notes/Notes.tsx:175-189.

FittingSettings::is_valid is never called, so an invalid prior_scale behaves like "model". The model fit demo rates Good when neither check ran. PK-Library/…/graphicanalysis.cpp:748-755; PreciseRx-Web/…/ModelFitDemo/fitMetrics.ts:234-260. Engine side · Demo

RUM runs on 100% of sessions with 100% replay and mask-user-input. The FHIR Patient resource is sent as an action with birthdate, MRN, gender and race extensions; only the name is redacted. High Hard-deleting a case may erase its audit trail

The audit row cascades with the case, and the audit writer swallows every error. This depends on whether production's schema matches the ORM. PreciseRx-Database/app/models/hospital/edithistory.py:13-17; app/middlewares/edithistory.py:145-146. Details

It authenticates with the identifier in the path, but provisions against the one in the token response. PreciseRx-Databridge/src/controllers/ehr/epic/get-callback.js:165-182.
